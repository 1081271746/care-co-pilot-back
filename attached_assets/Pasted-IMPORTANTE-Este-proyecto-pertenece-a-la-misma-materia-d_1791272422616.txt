==================================================
PROYECTO
==================================================

Nombre provisional:

"Co-Piloto de Duelo"

Idea:

Sistema de acompañamiento emocional estructurado después de una pérdida, utilizando IA de manera responsable y con varias etapas de acompañamiento.

CASO REAL:

Las personas que atraviesan un proceso de duelo muchas veces no tienen acompañamiento estructurado fuera de terapia.

La terapia puede ser costosa o tener listas de espera, mientras que muchas aplicaciones existentes solamente ofrecen contenido genérico de mindfulness.

La propuesta es crear una aplicación web que permita llevar un diario emocional, recibir ejercicios y recursos adaptados al proceso emocional detectado por el sistema y recibir orientación responsable cuando se detecten señales de riesgo.

IMPORTANTE:

El sistema NO reemplaza a un psicólogo, psiquiatra, terapeuta ni servicio de emergencia.

No debe realizar diagnósticos médicos.

La IA debe utilizarse como herramienta de acompañamiento y orientación estructurada, no como profesional de salud mental.

==================================================
IA Y ANÁLISIS EMOCIONAL
==================================================

Esta es una parte central del proyecto.

La IA debe analizar el contenido del diario para identificar patrones emocionales.

La idea inicial contempla las etapas clásicas del duelo:

- negación;
- ira;
- negociación;
- depresión;
- aceptación.

IMPORTANTE:

Estas etapas NO deben tratarse como diagnóstico médico.

La IA debe expresar los resultados como una estimación orientativa basada en el contenido escrito.

Por ejemplo:

"El contenido presenta señales compatibles con una etapa de tristeza intensa."

No:

"El usuario tiene depresión."

La clasificación debe poder utilizarse para adaptar el acompañamiento.

==================================================
ACOMPAÑAMIENTO MULTIETAPA
==================================================

Dependiendo del análisis, el sistema puede recomendar:

NEGACIÓN:

- ejercicios de reconocimiento emocional;
- escritura reflexiva;
- recursos sobre aceptación de la pérdida.

IRA:

- ejercicios de regulación emocional;
- escritura guiada;
- técnicas de identificación de emociones.

NEGOCIACIÓN:

- ejercicios de reflexión;
- identificación de pensamientos recurrentes;
- escritura sobre aquello que la persona desea cambiar.

DEPRESIÓN / TRISTEZA INTENSA:

- ejercicios suaves;
- recursos de apoyo;
- actividades de autocuidado;
- recomendaciones de buscar acompañamiento profesional cuando corresponda.

ACEPTACIÓN:

- ejercicios de integración;
- reflexión;
- construcción de nuevos hábitos;
- memoria positiva.

No quiero que el sistema trate estas etapas como un proceso obligatorio ni lineal.

La persona puede cambiar entre estados.

==================================================
DETECCIÓN DE RIESGO
==================================================

ESTA PARTE ES CRÍTICA.

El sistema debe tener reglas éticas estrictas.

Debe detectar posibles señales de:

- ideación suicida;
- autolesión;
- crisis emocional grave;
- peligro inmediato.

Cuando exista una señal de riesgo:

NO debe continuar simplemente con ejercicios normales.

Debe mostrar un mensaje de seguridad.

Debe recomendar buscar ayuda profesional.

Debe mostrar recursos de emergencia apropiados.

Debe dejar claro que la aplicación no sustituye atención profesional.

IMPORTANTE:

No quiero que la IA intente "tratar" una crisis.

No quiero respuestas peligrosas.

No quiero que el sistema minimice expresiones como:

"quiero morir"

"no quiero seguir"

"quiero hacerme daño"

"no puedo más"

Si se detecta una señal grave, debe priorizar la seguridad.
